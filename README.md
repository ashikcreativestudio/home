# Ashik Creative Studio — GitHub Pages ওয়েবসাইট

এটি Ashik Creative Studio এর হোম পেজের স্ট্যাটিক সংস্করণ। WordPress থিম থেকে তৈরি, GitHub Pages এ বিনামূল্যে চলবে। কোনো সার্ভার, ডাটাবেস বা PHP লাগে না।

## ফাইল ও ফোল্ডার

| ফাইল / ফোল্ডার | কাজ |
|---|---|
| `index.html` | পুরো হোম পেজ (হিরো, সেবা, শপ/কার্ট/চেকআউট, ট্র্যাক, কাজের নমুনা, FAQ, যোগাযোগ) এবং সেটিংস |
| `style.css` | ডিজাইন, ডার্ক মোড ও রেসপন্সিভ লেআউট |
| `assets/img/` | লোগো, ছবি, QR ও পেমেন্ট লোগো |
| `assets/js/main.js` | হোম পেজের স্ক্রিপ্ট (সেবা, FAQ, ভাষা, মেনু) |
| `assets/js/shop.js` | শপ, কার্ট, চেকআউট ও অর্ডার ট্র্যাক |
| `assets/js/static-db.js` | অর্ডার ও মেসেজ সংরক্ষণের লেয়ার (ব্রাউজারে) |
| `.nojekyll` | GitHub যেন `assets` ফোল্ডার বাদ না দেয় |

## GitHub Pages এ আপলোড করার ধাপ

1. zip ফাইলটি কম্পিউটারে Extract করুন। **zip ফাইলটি নয়, ভিতরের ফাইলগুলো** আপলোড করতে হবে।
2. GitHub এ একটি **Public** repository তৈরি করুন, নাম `home` (এতে URL হবে `https://ashikcreativestudio.github.io/home/`)। `home` নামের repository আগে থেকে থাকলে সেটিতেই আপলোড করুন।
3. **Add file → Upload files** এ যান। `index.html`, `style.css`, `.nojekyll`, `assets` ফোল্ডার ও `README.md` টেনে আনুন, তারপর **Commit changes** চাপুন।
4. **Settings → Pages** এ যান। **Source** এ **Deploy from a branch** বেছে নিন, Branch: `main`, Folder: `/ (root)`, তারপর **Save**।
5. ১–২ মিনিট অপেক্ষা করে সাইট খুলুন।

> GitHub Pages বিনামূল্যে ব্যবহার করতে repository **Public** হতে হবে।

## সেটিংস বদলানো

সব গুরুত্বপূর্ণ তথ্য `index.html` এর শেষের দিকে দুটি `<script>` ব্লকে আছে:

- **`window.ACWP`**: WhatsApp নম্বর (ডিফল্ট `8801303216921`), ফোন নম্বর ডিসপ্লে, Facebook লিংক, পরিসংখ্যান।
- **`window.SHOP_CONFIG`**: bKash / Nagad / Rocket নম্বর, প্যাকেজের নাম, দাম (`price`) ও ক্যাটাগরি।

পরিবর্তনের পর ফাইলটি আবার GitHub এ আপলোড (বা Edit করে Commit) করুন।

**সেবা কার্ড ও FAQ** বদলাতে `assets/js/main.js` এর `SERVICES` ও `FAQ` অংশ সম্পাদনা করুন।

**ছবি বদলাতে:** `assets/img/` এর একই নামের ফাইল (যেমন `me.webp`, `w1.webp`) নতুন ছবি দিয়ে প্রতিস্থাপন করুন। WebP ফরম্যাট ব্যবহার করলে সাইট দ্রুত লোড হয়।

## গুরুত্বপূর্ণ সীমাবদ্ধতা

- **অর্ডার সার্ভারে জমা হয় না।** অর্ডার ও মেসেজ ক্রেতার নিজের ব্রাউজারে (localStorage) জমা হয়। ক্রেতাকে অর্ডারের বিবরণ WhatsApp এ পাঠানোর বাটনও দেখানো হয়, তাই আপনি WhatsApp এ সব অর্ডার পাবেন।
- **অর্ডার ট্র্যাক** শুধু সেই ব্রাউজারে কাজ করে যেখানে অর্ডারটি দেওয়া হয়েছে।
- **অর্ডার স্ট্যাটাস আপডেট** (কনফার্ম / কাজ চলছে / ডেলিভারড) করার WordPress ড্যাশবোর্ড এখানে নেই।
- **পেমেন্ট যাচাই** নিজে bKash / Nagad / Rocket অ্যাপে মিলিয়ে নিতে হবে।
- `/web-services/` পেজ এই সংস্করণে নেই।

অর্ডার কেন্দ্রীয়ভাবে সংরক্ষণ করতে চাইলে Google Sheets + Apps Script এর মতো একটি বিনামূল্যের সার্ভিস যুক্ত করা যায়।
